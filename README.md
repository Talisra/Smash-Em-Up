# Smash Em Up
 Game developed with Unity

## Soundtrack stem player
`Tools/soundtrack-player.html` plays the layered soundtrack (`Assets/Audio/Soundtrack`) in the browser: mute, solo and
mix stems, jump between or loop sections A/B/C. Serve the repo root (`python3 -m http.server`) and open
`localhost:8000/Tools/soundtrack-player.html`, or open the file directly and drop the Soundtrack folder (or any folder of stems) on it.
